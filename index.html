Studio Delivery Tool

A private desktop tool that delivers finished video files to its owner's Google Drive and updates the owner's Google Sheets planning documents.

What it is

The tool is a set of command-line scripts that run only on the owner's own computer. It is not a public service, it has no user accounts and it is not offered to other people. It is used by one person: its owner.

What it does

  • Watches a local folder for finished video files.
  • Uploads those files to a specific folder in the owner's Google Drive and checks that the upload is complete.
  • Writes the title, Drive link and status of each delivered video into a planning spreadsheet in the owner's Google Sheets.

Google sign-in

The tool uses Google OAuth to access the owner's own Google Drive and Google Sheets. Access can be revoked at any time at myaccount.google.com/permissions.
